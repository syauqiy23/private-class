# Private Class — AI Automation untuk Bisnis

Repo ini adalah **sumber kebenaran** untuk rencana kelas private AI (Claude) milik Syauqiy.
Semua plan, keputusan, dan hasil diskusi disimpan di sini supaya siapa pun yang punya akses
repo bisa langsung lanjut tanpa ngulang chat dari awal.

## Mulai dari mana

| File | Isi |
| --- | --- |
| [`docs/plan-private.md`](docs/plan-private.md) | **Plan aktif.** 5 paket result private, arsitektur, prasyarat, harga draf, next steps |
| [`docs/riset-api-scalev.md`](docs/riset-api-scalev.md) | Hasil cek API Scalev: endpoint yang kepake buat R1/R4, bukti data UTM, risiko |

## Status sekarang (update tiap ada perubahan)

- **Fokus:** private dulu. Ecourse/LMS **ditunda** (belum ada waktu rekaman).
- **Fase:** finalisasi paket & arsitektur, belum ada peserta. API Scalev udah dicek (aman buat R1 & R4).
- **Next step terdekat:** lihat checklist di `docs/plan-private.md` → bagian *Next steps*.

## Aturan main repo

1. Tiap diskusi yang menghasilkan keputusan → tambahin 1 entri di `docs/keputusan.md`.
2. Plan berubah → edit `docs/plan-private.md` langsung (jangan bikin file plan baru), update bagian *Status* di atas.
3. Plan yang dibatalkan/ditunda → pindah ke `docs/arsip-*.md`, jangan dihapus.
4. Angka harga/biaya tools yang belum dicek ulang ditandai **(draf)** atau **(cek ulang)**.
