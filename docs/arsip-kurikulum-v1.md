("otak bisnis") · ubah SOP jadi skill · connector Drive/Gmail/Calendar/Canva.

**T2 — AI Product Builder:** riset produk (pola Waroeng Dokumen) · outline + sampel lalu produksi massal ·
produksi batch + handoff · copywriting LP & iklan · LP anti-slop di Cloudflare · checkout & pengiriman Scalev ·

**T3 — AI Agent Sales & CS:** peta agent · jalur no-code (Zernio + scheduled task) · jalur API resmi (Meta app,
Threads/IG API, token di Supabase) · persona & rules · WhatsApp Cloud API tanpa BSP · data Scalev + notif transfer ·
biaya murah (Haiku + caching) · studi kasus bot Threads, WA CS SantriPreneur.

T4 tidak dijadikan ecourse karena aksesnya ke ad account dan duit iklan peserta.
